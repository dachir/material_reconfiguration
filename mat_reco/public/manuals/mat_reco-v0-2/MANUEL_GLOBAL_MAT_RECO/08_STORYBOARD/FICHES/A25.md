# A25 — Gérer les casses successives



## Position dans le flux

Flux 3 · Atelier

## Objectif

Reprise de production traçable.

## Pourquoi cette étape existe

Garder la trace d’une nouvelle casse sur un remplacement sans dupliquer la demande client.

## Quand l’utiliser

Au passage indiqué du flux, après contrôle des entrées nécessaires.

## Qui l’exécute

Opérateur ou responsable atelier habilité

## Document

Material Cutting Plan / UX 2.0

## Entrées / prérequis

Remplacement identifié ; nouveau constat de casse.

## Actions

1. Créer un nouvel incident sur la pièce concernée.
2. Confirmer et appliquer.
3. Relire le besoin restant.
4. Recalculer une compensation adaptée.

## Contrôles

- Opérations antérieures conservées.
- Une seule unité commerciale due.
- Production / consommation déjà soumises figées.

## Résultat

Reprise de production traçable.

## Étape suivante

A19

## Attention

Ne pas supprimer les événements précédents pour fabriquer une seconde demande ; solliciter le responsable si la pièce est déjà engagée dans un Repack soumis.
