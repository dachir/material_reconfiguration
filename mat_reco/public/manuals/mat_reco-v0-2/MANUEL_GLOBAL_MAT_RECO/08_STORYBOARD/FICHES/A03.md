# A03 — Charger les commandes client



## Position dans le flux

Flux 3 · Atelier

## Objectif

Commandes sélectionnées.

## Pourquoi cette étape existe

Limiter le calcul aux commandes à traiter pendant cette préparation.

## Quand l’utiliser

Au passage indiqué du flux, après contrôle des entrées nécessaires.

## Qui l’exécute

Opérateur ou responsable atelier habilité

## Document

Material Cutting Plan / UX 2.0

## Entrées / prérequis

MCP avec Source Item ; commandes liées à cette matière.

## Actions

1. Dans Outils, choisir Select Orders for Source Item.
2. Lire les commandes proposées.
3. Conserver le périmètre voulu.

## Contrôles

- Bonne commande.
- Bonne matière parent.
- Quantité demandée.

## Résultat

Commandes sélectionnées.

## Étape suivante

A04

## Attention

Ne pas poursuivre si un contrôle reste incohérent.
