# A28 — Préparer la clôture et la soumission MCP



## Position dans le flux

Flux 3 · Atelier

## Objectif

Plan contrôlé pour la phase stock.

## Pourquoi cette étape existe

Clôturer les contrôles atelier sans inventer un ordre de soumission ERP non validé.

## Quand l’utiliser

Au passage indiqué du flux, après contrôle des entrées nécessaires.

## Qui l’exécute

Opérateur ou responsable atelier habilité

## Document

Material Cutting Plan / UX 2.0

## Entrées / prérequis

Plan effectif ; besoin couvert ; droits ; procédure interne.

## Actions

1. Appliquer les incidents et contrôler les résultats.
2. Faire vérifier la couverture par le responsable.
3. Choisir le circuit de soumission MCP / Repack approuvé sur le site.

## Contrôles

- Besoins non couverts bloquants.
- Document prêt pour les contrôles stock.
- Responsable de validation connu.

## Résultat

Plan contrôlé pour la phase stock.

## Étape suivante

S01 / S02

## Attention

L’ordre exact de soumission MCP et Repack reste une décision ouverte. La soumission MCP verrouille les modifications atelier.
