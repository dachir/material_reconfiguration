# A11 — Sélectionner une pièce et utiliser le menu contextuel



## Position dans le flux

Flux 3 · Atelier

## Objectif

Action préparée.

## Pourquoi cette étape existe

Préparer une action sur la bonne unité ou zone physique.

## Quand l’utiliser

Au passage indiqué du flux, après contrôle des entrées nécessaires.

## Qui l’exécute

Opérateur ou responsable atelier habilité

## Document

Atelier UX 2.0 · menu contextuel

## Entrées / prérequis

Plaque courante ; pièce / chute / déchet à traiter.

## Actions

1. Cliquer la zone.
2. Lire ses dimensions.
3. Choisir dans le menu une action autorisée.

## Contrôles

- Bonne plaque et bonne unité.
- Menus selon type de zone.
- Curseur d’action et cible compatible.

## Résultat

Action préparée.

## Étape suivante

A12–A17 selon constat

## Attention

Le curseur d’interdiction indique une cible incompatible, pas une défaillance du menu.
