# S12 — Comprendre Material Reconfiguration historique



## Position dans le flux

Flux 3 · Stock / Recomposition

## Objectif

Circuit historique identifié.

## Pourquoi cette étape existe

Connaître un circuit ancien sans le mélanger avec le MCP UX 2.0.

## Quand l’utiliser

Au passage indiqué du flux, après contrôle des entrées nécessaires.

## Qui l’exécute

Responsable stock habilité

## Document

Material Reconfiguration

## Entrées / prérequis

Material Reconfiguration ; commande ; produit ; matière.

## Actions

1. Lire le plan proposé et les lignes Detail.
2. Contrôler un éventuel plan partiel.
3. Soumettre uniquement selon le circuit historique validé.
4. Utiliser Create Repack (New, Bundled) pour le Stock Entry associé.

## Contrôles

- Raw Material / Finished Good / By Product.
- Changement d’état de séries à la soumission historique.
- Annulation spécifique.

## Résultat

Circuit historique identifié.

## Étape suivante

S13 si ce circuit est retenu

## Attention

Ce document a une logique de soumission / annulation distincte. La procédure Réinitialiser du MCP ne s’y applique pas.
