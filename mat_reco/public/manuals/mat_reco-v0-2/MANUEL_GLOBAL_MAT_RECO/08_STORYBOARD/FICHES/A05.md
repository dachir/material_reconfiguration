# A05 — Qualifier les plaques



## Position dans le flux

Flux 3 · Atelier

## Objectif

Matières admissibles définies.

## Pourquoi cette étape existe

Autoriser le calcul à utiliser uniquement les matières que l’atelier accepte.

## Quand l’utiliser

Au passage indiqué du flux, après contrôle des entrées nécessaires.

## Qui l’exécute

Opérateur ou responsable atelier habilité

## Document

Material Cutting Plan / UX 2.0

## Entrées / prérequis

Table MCP Stock Candidate ; matière physique contrôlée.

## Actions

1. Relire chaque plaque ou chute.
2. Cocher / décocher Is Qualified selon le choix voulu.
3. Enregistrer avec la sélection vérifiée.

## Contrôles

- Is Qualified : admissible au calcul.
- Is Active Input : réellement utilisé.
- Les deux colonnes ne sont pas interchangeables.

## Résultat

Matières admissibles définies.

## Étape suivante

A06

## Attention

Qualifier une série ne constitue pas une consommation de stock.
