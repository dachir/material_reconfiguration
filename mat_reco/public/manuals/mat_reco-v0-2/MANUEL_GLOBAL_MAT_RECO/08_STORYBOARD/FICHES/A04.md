# A04 — Charger les matières disponibles



## Position dans le flux

Flux 3 · Atelier

## Objectif

Serial No candidats chargés.

## Pourquoi cette étape existe

Présenter au calcul les séries utilisables, dans le dépôt choisi.

## Quand l’utiliser

Au passage indiqué du flux, après contrôle des entrées nécessaires.

## Qui l’exécute

Opérateur ou responsable atelier habilité

## Document

Material Cutting Plan / UX 2.0

## Entrées / prérequis

Source Item ; Source Warehouse ; variantes.

## Actions

1. Choisir Get Stock.
2. Contrôler les séries et dimensions chargées.
3. Actualiser si le stock a changé.

## Contrôles

- Séries Full / Partial.
- Dimensions positives.
- Épaisseur et dépôt cohérents.

## Résultat

Serial No candidats chargés.

## Étape suivante

A05

## Attention

Les lignes chargées sont initialement qualifiées : revoir cette sélection avant calcul.
