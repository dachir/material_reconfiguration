# A20 — Ouvrir la compensation



## Position dans le flux

Flux 3 · Atelier

## Objectif

Session de compensation ouverte.

## Pourquoi cette étape existe

Ouvrir la recherche des remplacements sans quitter la disposition de l’atelier.

## Quand l’utiliser

Au passage indiqué du flux, après contrôle des entrées nécessaires.

## Qui l’exécute

Opérateur ou responsable atelier habilité

## Document

Material Cutting Plan / UX 2.0

## Entrées / prérequis

MCP Retour Terrain brouillon ; incidents appliqués.

## Actions

1. Cliquer Compenser près de Réinitialiser.
2. Lire dimensions et quantité à compenser.
3. Lire les sources de stock à droite.
4. Choisir Automatique ou Manuel.

## Contrôles

- Bonne commande.
- Stock admissible.
- Mode de compensation.

## Résultat

Session de compensation ouverte.

## Étape suivante

A21 / A22 / A23 selon source

## Attention

L’ajout matière est sélectionné dans le panneau de stock ; le dessin reste une plaque par page.
