CHANTIER · 01

Repérer les zones de travail

Le chantier décrit le besoin commercial du client : les produits attendus, leurs dimensions, les prix et les prestations. La fiche technique définit ensuite la fabrication des découpes et ouvrages à produire.

ZoneUtilisation
En-têteClient, responsable, devise, remise, modèle de taxes et dates.
TypesDésignation et épaisseur communes ; unité de prix et prestations par défaut.
SectionsOrganisation du chantier : bâtiment, étage, façade, pièce…
GrilleUne ligne par dimension ou besoin à chiffrer.
Triangle vertAfficher la section et les prestations de la ligne.
Menu •••Validation, devis, duplication, impression et autres actions autorisées.
Type et section sont différents

Un même type peut être utilisé dans plusieurs sections. Une section peut contenir plusieurs types. Choisissez la section pour localiser l’ouvrage, et le type pour décrire ce que vous vendez.

CHANTIER · 02

Créer ou retrouver un chantier

  1. Ouvrir Univers Glass → Chantiers. L’adresse directe est https://fimaci.f.frappe.cloud/app/chantiers.
  2. Pour reprendre un dossier, rechercher son numéro ou sa désignation dans le champ Chantier, puis choisir le résultat.
  3. Pour créer un dossier, cliquer sur + Nouveau. Renseigner la désignation, la société et le client ; préciser le responsable et les dates utiles.
  4. Choisir le modèle de taxes si nécessaire, puis Enregistrer. Le numéro de chantier est attribué automatiquement.
Le brouillon est l’espace de préparation

Compléter et enregistrer le chantier avant sa validation. Les modifications non enregistrées restent dans l’écran courant et peuvent être perdues en changeant de page.

Le total affiché sur Chantier est HT

La grille affiche le total hors taxes après remise. Contrôler les taxes et le total final dans le devis avant de le valider ou de l’imprimer.

CHANTIER · 04

Définir un type d’ouvrage

Pour les ouvrages à fabriquer, commencer par créer le type : une désignation commerciale compréhensible par le client, une épaisseur et une unité de prix par défaut.

  1. Cliquer sur + Type.
  2. Saisir ou rechercher la Désignation commerciale. Le champ propose des désignations existantes tout en permettant une saisie libre.
  3. Renseigner une épaisseur positive en millimètres, puis choisir PC ou M2.
  4. Cliquer sur Enregistrer dans la fenêtre : le type est ajouté à la saisie en cours. Enregistrer ensuite le chantier pour le conserver.

La bulle du type sert de filtre. Ses petits boutons permettent de modifier le type, d’ouvrir ses services et accessoires ou de le supprimer. Un type utilisé par des lignes doit être réaffecté avant de pouvoir être supprimé.

Une description proposée, puis ajustable

La désignation du type est proposée sur les nouvelles lignes. Vous pouvez ensuite adapter la description d’une ligne sans changer la désignation commune.

CHANTIER · 05

Saisir les lignes et choisir PC ou M2

  1. Sélectionner la bulle du type à utiliser, puis cliquer sur + Ajouter une ligne.
  2. Vérifier la description proposée. Saisir la longueur et la hauteur en millimètres ; l’épaisseur provient du type.
  3. Saisir la quantité de pièces, l’unité de prix et le prix unitaire.
  4. Ajouter les autres dimensions comme des lignes distinctes. Le bouton de duplication d’une ligne permet de reprendre une saisie proche.
Unité de prixCalcul du montant HT avant remise
PCQuantité de pièces × prix unitaire.
M2Quantité de pièces × (longueur en mm × hauteur en mm ÷ 1 000 000) × prix au m².
Exemple M2

2 pièces de 1 500 × 1 000 mm représentent 3 m². À 95 000 par m², le montant HT avant remise est de 285 000. L’unité choisie sur le type est un défaut ; vérifiez celle de chaque ligne.

CHANTIER · 06

Appliquer les services et accessoires du type

Les prestations communes évitent de ressaisir les mêmes services et accessoires pour chaque dimension.

  1. Sur la bulle du type, cliquer sur l’icône Services et accessoires.
  2. Dans le volet de droite, rechercher et cocher les prestations utiles.
  3. Renseigner le prix unitaire par défaut et, selon la prestation, la quantité par pièce ou le coefficient.
  4. Cliquer sur Appliquer au type. Le volet se ferme ; les lignes de ce type héritent de ces prestations.
  5. Vérifier le résultat sur les lignes, puis Enregistrer le chantier.
Les dimensions de chaque ligne comptent

Une prestation au périmètre est calculée sur le périmètre de chaque ouvrage ; une prestation à la surface utilise sa surface. Les lignes ne reprennent donc pas forcément la même quantité de prestation.

Survolez la bulle du type pour consulter ses prestations communes et leurs valeurs par défaut.

CHANTIER · 07

Consulter et ajuster une prestation de ligne

  1. Cliquer sur le triangle vert d’une ligne pour voir les prestations qui lui sont rattachées.
  2. Pour un ajout ou un ajustement, ouvrir l’icône Services / Accessoires de la ligne.
  3. Dans Compléments de ces lignes, ajuster la quantité, le prix, la remise ou le montant lorsque nécessaire.
  4. Pour ajouter une prestation, la cocher dans le catalogue puis cliquer sur Affecter à cet ouvrage. Pour plusieurs lignes cochées, utiliser Affecter aux ouvrages sélectionnés.
  5. Le volet se ferme après l’affectation. Enregistrer le chantier pour conserver les modifications.

Une prestation héritée du type est indiquée comme telle. Ses quantités et prix peuvent être ajustés pour une ligne ; les autres lignes conservent leurs propres valeurs.

CHANTIER · 08

Organiser le chantier avec des sections

Les sections structurent le chantier et son impression : bâtiment, étage, façade ou pièce. Elles restent disponibles pendant la préparation du chantier, même après l’ajout des types et des lignes.

  1. Cliquer sur + Section. Saisir son nom et, si nécessaire, choisir une section parente.
  2. Pour ranger une ligne, utiliser son bouton Affecter une section. Les sections apparaissent alors à gauche avec une case de choix pour la ligne en cours.
  3. Choisir la section souhaitée puis terminer le choix. Enregistrer le chantier.
  4. Cliquer sur une section pour filtrer la grille ; Tout le chantier retire ce filtre. Le bouton « permet de replier le volet.
Réutiliser une structure

Le menu Gestion des sections permet de récupérer une arborescence depuis un modèle ou un autre chantier. Cette récupération ajoute les sections ; elle ne copie pas les lignes d’ouvrage. Les actions disponibles dépendent de vos droits.

CHANTIER · 09

Traiter une vente directe

Une plaque entière, un accessoire ou un service vendu seul ne nécessite pas de type d’ouvrage ni de fiche technique. Il s’agit d’une vente directe.

  1. Cliquer sur Tous, à côté des bulles de types.
  2. Cliquer sur + Ajouter une ligne : la fenêtre de vente directe s’ouvre.
  3. Choisir l’article existant, saisir la quantité et le prix, et adapter la description si nécessaire.
  4. Enregistrer la fenêtre, puis le chantier.
Chantier et commande mixtes

Un même dossier peut contenir des ventes directes et des ouvrages à fabriquer. La fiche technique concerne les découpes et ouvrages ; les plaques entières, accessoires et services restent dans le circuit commercial direct.

CHANTIER · 10

Gérer les remises

ModeComportement attendu
PourcentageLa remise par défaut est proposée sur les lignes et les prestations. Les montants des lignes sont calculés après cette remise.
Exception sur une ligneSaisir la remise propre à cette ligne, par exemple 0 % lorsqu’elle est exclue de la remise générale.
MontantLa remise porte globalement sur le total. Les pourcentages de remise des lignes ne s’appliquent pas en plus.
  1. Choisir le mode de remise dans l’en-tête et saisir sa valeur.
  2. Vérifier les exceptions dans la colonne Remise (%) des lignes et dans les prestations.
  3. Contrôler le Total HT après remise, puis enregistrer le chantier.
  4. Vérifier les remises et les taxes dans le devis et son impression.
Ne pas confondre prix et remise

Le prix unitaire est le prix avant la remise de ligne. Une remise globale en montant est retranchée du total ; ne la saisir pas une seconde fois dans les prix unitaires.

CHANTIER · 11

Enregistrer et valider le chantier

  1. Contrôler le client, les types, les descriptions et les sections.
  2. Vérifier toutes les dimensions, quantités, unités PC/M2, prix et prestations. Contrôler le modèle de taxes et les remises.
  3. Cliquer sur Enregistrer. Attendre la fin de l’enregistrement.
  4. Dans le menu •••, choisir Valider le commercial, puis confirmer. Cette action nécessite le droit de validation.
  5. Le chantier validé peut servir à préparer le devis. Sa grille n’est plus modifiable comme un brouillon.
Point de départ du cockpit commercial

Le cockpit commercial commence aux chantiers validés, pour tous ses utilisateurs. Les brouillons se préparent dans l’écran Chantier ; ils ne sont pas à traiter par le responsable commercial dans le cockpit.

Le statut métier Préparation peut encore être affiché sur un chantier validé. Ne le confondez pas avec le badge Brouillon commercial : vérifiez la disponibilité des actions et le caractère modifiable de la grille.

CHANTIER · 12

Préparer le devis puis la commande

  1. Dans le chantier validé, cocher les lignes à inclure au devis.
  2. Ajuster les quantités à deviser si vous ne traitez qu’une partie du besoin. Les quantités déjà reprises dans un devis actif sont prises en compte.
  3. Dans •••, choisir Générer un devis. Choisir s’il faut également le valider, puis lancer la génération.
  4. Contrôler le devis : descriptions, sections, dimensions, unités, services et accessoires, remises et taxes.
  5. Après acceptation client, préparer la commande depuis le devis ou le cockpit commercial. Choisir le circuit A ou B si cette option est autorisée.
La fiche technique vient après la commande

La validation de la commande déclenche la préparation technique et les tâches associées lorsqu’il y a des découpes ou ouvrages à fabriquer. Le chantier commercial n’exige pas la fiche technique pour être validé ou pour préparer le devis.

Dans le cockpit atelier, seules les lignes de fabrication dont la fiche technique est validée sont proposées. Une vente directe n’a pas à passer par cette préparation technique.

CHANTIER · 13

Dupliquer, actualiser ou amender

ActionUtilisation
Dupliquer le chantierCréer un nouveau brouillon à partir d’un chantier existant, puis adapter le client, les dimensions, les prix et les prestations. La copie reste dans la vue Chantier.
ActualiserRecharger les données enregistrées sur le serveur. En présence de modifications locales, confirmer leur abandon uniquement si vous ne voulez pas les conserver.
Annuler puis amenderSur un chantier validé admissible, annuler le document puis préparer sa révision en brouillon.
AmenderDepuis un chantier déjà annulé, créer son amendement si vos droits le permettent.
Imprimer A4Ouvrir l’impression du chantier. L’impression du devis se fait sur le devis, avec son format de devis.
Une annulation peut être interdite

Un chantier déjà utilisé dans un devis, une commande ou un plan de découpe ne peut pas être annulé par cette action. Le bouton peut être désactivé pour cette raison.

Travail à plusieurs

Les bulles d’utilisateurs indiquent les personnes présentes. Si un avertissement signale que le chantier a changé, vos saisies ne sont pas automatiquement écrasées. Vérifiez les changements avec les personnes concernées, puis utilisez Actualiser pour recharger la version du serveur.

Avant de quitter l’écran

Vérifier qu’aucun message Modifications non enregistrées ne subsiste. Les changements faits dans les fenêtres de types ou dans le volet des prestations doivent aussi être enregistrés sur le chantier.

Si une action est absente

Vérifier l’état du dossier, les modifications en attente et les droits du compte. Un chantier validé propose moins d’actions de saisie qu’un brouillon. Demander au responsable habilité de valider lorsque cette action n’est pas autorisée.
